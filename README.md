# News Explorer

An Android application that allows users to explore countries and browse news related to each country.

## About

News Explorer is an Android application built with Kotlin. Users can browse a list of countries and select a country to view its related news, including headlines and images.

The application uses a remote API to fetch news and Room Database to store news locally.

## Features

- Browse a list of countries.
- View news related to selected countries.
- Display news headlines and images.
- Fetch news from a remote API.
- Store news locally using Room Database.
- Organized application architecture using MVVM.

## Technologies Used

- Kotlin
- Retrofit
- Room Database
- Hilt
- MVVM
- Coroutines
- RecyclerView
